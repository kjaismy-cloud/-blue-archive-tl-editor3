# V4.5 Chrome 桌面版

## 桌面版
Chrome / Edge / Safari 桌面瀏覽器寬度 >= 980px 時，自動切換成三欄：

- 左欄：Boss + 隊伍
- 中欄：學生搜尋 / 篩選 / 學生卡片 / 詳細技能
- 右欄：TL 編輯器

## 手機版
寬度 < 980px 時保留原本 iPhone 底部導覽操作。

## 保留功能
- 253 名學生本地 JSON
- 中文名稱
- STRIKER 4 + SPECIAL 2
- SquadType / TacticRole
- Boss 內嵌 / 本地資料
- 學生圖片 fallback
- JSON 匯入匯出
- TL 編輯器
